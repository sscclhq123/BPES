# SALDOP agent instructions

- For any UI, UX, responsive-layout, visualization, typography, accessibility, or motion change, consult the `ui-skills` MCP catalog first.
- Start with its routing guidance, then load only the smallest relevant UI skill before reading or changing the affected frontend code.
- Apply the selected guidance to the implementation and verify the result with Playwright CLI on both desktop and mobile viewports.
- Use Context7 when current framework or library API documentation is relevant.
- Deploy completed SALDOP changes to `https://saldop.vercel.app/` and verify the production deployment.
