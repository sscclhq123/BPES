# SALDOP frontend source

This directory is the editable source for the SALDOP studio interface.
Production is served only from `https://saldop.vercel.app/` through the
`sscclhq123/BPES` GitHub repository. Do not publish this source with Sites.

After a validated frontend build, copy the generated browser assets into
`../studio/` and deploy through the repository's existing Vercel integration.
