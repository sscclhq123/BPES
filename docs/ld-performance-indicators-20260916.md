# LD 성능 지표: 2026-09-16

## 변경 범위
- 결과 집열기 면적 / 사용자가 입력한 건축면적 × 100. 주차장 면적은 분모에 합산하지 않으며 옥상 실점유율이 아니다. 100% 초과를 제한하지 않는다.
- 적산 로그 후처리만 추가. 실험식, 제어, TES, 기존 LD 사전계산 캐시를 변경하지 않았다.
- 지역 요약 선택에 연동되는 성능 카드와 월별 표.

## 정의
1. 제습 목표량 충족률 = Σ min(시간별 실제량, 시간별 목표량) / Σ 목표량. 과잉 제습이 다른 시간 미충족을 상쇄하지 않는다. 허용습도 상한 초과시간과 별도 지표.
2. 수분 배출/흡수 비 = Σ 재생 배출량 / Σ 제습 흡수량. 탱크의 기간 수분수지 지표이지 접촉기 효율이 아니다. 초기·종료 상태에 따라 100% 초과 가능.
3. 단위 재생열 = Σ REG_HX_HEAT_NEED_kWh / Σ 배출 수분 kg. 공급원 구성과 무관한 요구열 기준. 전력·냉각열 제외. 전체 시스템 COP 아님.
4. 재생 외기 실험범위 이탈률 = 범위 밖 외기에서의 재생 ON 등가시간 / 전체 재생 ON 등가시간. 범위: 30.3–36.6°C 및 10.5–22.0 g/kgDA. 두 조건 중 하나라도 이탈하면 포함. 모든 내부 용액상태·유량까지 검증한 비율은 아님.
5. 분모 0이면 해당 지표 미정의(null/—). 시간별 kg/h는 dt_h로 적산; kWh는 다시 dt를 곱하지 않음.

## 문헌과 코드 구분
검토 문헌: Jo & Jeong (2017), DOI 10.12972/jkiaebs.20170002, https://www.jkiaebs.org/articles/xml/ENqk/ (제습·재생, 평형상태, 성능식 설명).
수분전달 유효도 정의: 제습 (wi−wo)/(wi−weq), 재생 (wo−wi)/(weq−wi). 효율이 아닌 유효도라는 의미를 명확히 해야 한다.
현재 코드 absorber_block은 회귀 유효도에 이상값 처리를 하고 출구습도를 제한한다. regenerator_block은 수분배출 상관식으로 출구습도를 계산한 뒤 유효도를 0–1로 제한한다. 제한된 수치는 물리·실험식 검증의 증거가 아니다.
시간별 저장 REG_AIR_OUT_w_kgkg는 마지막 내부 계산상태, 유량은 시간평균이다. 이들을 결합해 정확한 시간평균 접촉기 유효도로 표시하지 않았다. 향후 정확한 유효도는 내부 타임스텝에서 구동력·전달량·범위 이탈을 함께 적산해 새 캐시를 생성해야 한다. 이번 변경에서는 수행하지 않음.
재생 상관식 원문 계수·입력 단위에 대한 독립 검증은 완료되지 않았다. 본 지표 추가는 모델 실험 검증을 대체하지 않는다.
